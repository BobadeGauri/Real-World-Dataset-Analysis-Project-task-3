This project presents a complete exploratory data analysis workflow using the diabetes disease-progression dataset distributed with scikit-learn. The dataset contains 442 observations, ten standardized baseline features, and a quantitative target representing disease progression one year after baseline. The target is not a diagnosis of diabetes and the analysis is intended for educational purposes only.

The project begins with dataset inspection, including its dimensions, variables, numeric data types, missing values, duplicate observations, and descriptive statistics. To demonstrate practical data-cleaning methods, the raw working copy intentionally includes a small number of missing feature values and three duplicate observations. These issues were added for this exercise and are not defects claimed about the original source dataset. Duplicate observations are identified using the feature values and target while excluding the unique record ID. Missing numeric feature values are imputed using the median, and the cleaned dataset is exported for reproducibility.

Pandas and NumPy are used for data preparation and statistical calculations, while Matplotlib is used to create visualizations. The analysis includes a target distribution histogram, scatter plots comparing the target with BMI and blood-pressure features, a feature-correlation heatmap, and comparisons of target values across BMI-feature quartiles. Descriptive statistics and Pearson correlations are saved as output tables. The report explains the observed relationships without treating correlation as proof of causation.

The final Word report documents the dataset source, objectives, methodology, data-quality checks, cleaning decisions, visualizations, key findings, limitations, and conclusion. The project also includes the raw and cleaned CSV files, Python source code, output tables, plots, and README instructions. The work demonstrates a reproducible process for converting a raw dataset into a cleaner, more understandable analytical resource. Since the feature values are standardized and the target is a historical quantitative outcome, the results must not be interpreted as medical advice, diagnosis, or a clinical prediction.
